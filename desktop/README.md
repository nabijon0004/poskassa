# Paprika POS — программа кассы для Windows

`PaprikaPOS.exe` открывает страницу кассы (`/pos`) сервера в отдельном окне на
встроенном движке Microsoft Edge WebView2. Браузер не нужен.

Программа также **печатает чеки своей точки**: сервер в облаке не видит принтер
в локальной сети точки, поэтому программа раз в 2 секунды забирает с сервера
очередь печати точки (кухонные чеки, чеки покупателю, X/Z-отчёты) и отправляет
их на принтер по IP-адресу из админпанели. Пока в точке не запущена ни одна
программа кассы, чеки ждут в очереди (до 15 минут).

## Работа без интернета

Если связь с сервером пропала, касса продолжает работать: кассир входит по PIN,
продаёт (номера заказов О1, О2…), чеки печатаются сразу на принтер точки. Продажи
сохраняются на компьютере и сами отправляются на сервер, когда связь появится, —
в отчётах они будут со своим временем. Программа открывается и без интернета,
если хотя бы раз уже запускалась с интернетом на этом компьютере. Без связи нельзя
оплачивать заказы киоска, делать возвраты, печатать X/Z-отчёты и закрывать смену.

## Установка на компьютер кассира

1. В админпанели откройте точку → **Устройства** и добавьте кассу (или нажмите
   **Новый ключ** у существующей). Скопируйте ключ кассы.
2. Скопируйте `dist\PaprikaPOS.exe` в любую папку, например `C:\PaprikaPOS`.
3. Запустите. При первом запуске рядом появится `pos-config.json`.
4. Укажите адрес сервера (например `https://paprika.example.com`) и **ключ
   кассы**, нажмите «Подключиться». Настройки сохранятся.

Компьютер кассы должен быть в той же локальной сети, что и принтер точки.

Нужна среда **Microsoft Edge WebView2 Runtime** — в Windows 10/11 она обычно уже
есть. Если окно не открывается, установите её с
https://developer.microsoft.com/microsoft-edge/webview2/ (Evergreen Runtime).


## Клавиши

- **F11** — полный экран (запоминается)
- **F5** — обновить страницу
- **Ctrl+Shift+S** — сменить адрес сервера и ключ кассы

## Настройки (`pos-config.json`)

```json
{
  "server_url": "https://paprika.example.com",
  "device_key": "ключ кассы из админпанели",
  "fullscreen": false
}
```

Журнал работы — `pos-app.log` рядом с программой.

## Сборка

Нужен Python 3.10+. В папке `desktop` запустите `build.bat` — готовый файл
появится в `desktop\dist\PaprikaPOS.exe`. Программа не подписана цифровой
подписью, поэтому Windows SmartScreen при первом запуске может показать
предупреждение («Подробнее» → «Выполнить в любом случае»).
